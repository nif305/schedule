# منطق منصة توليد جدول الدورات التدريبية الأسبوعي

## الغرض

تحويل بيانات الدورات التدريبية الأسبوعية إلى مخرجات جاهزة للعرض والمشاركة.

## دورة العمل

1. إدخال رقم الأسبوع.
2. اختيار الموظف المسؤول.
3. إدخال الدورات يدويًا أو استيراد ملف Excel.
4. اختيار قالب التصميم.
5. توليد صور العرض أو تقرير الوكيل.
6. حفظ نسخة مؤرشفة من الجدول داخل المتصفح.

## البيانات الأساسية للدورة

- اسم الدورة.
- تاريخ البداية.
- تاريخ النهاية.
- القاعة.
- الطابق.
- الفترة.
- الحالة.
- المشرف.
- النوع.

## التخزين

التخزين الحالي محلي داخل المتصفح باستخدام LocalStorage، ولا توجد قاعدة بيانات أو تسجيل دخول.

## المخرجات

- ملف ZIP يحتوي صور العرض للشاشة.
- صورة JPG لتقرير الوكيل.
- قالب Excel للاستيراد.

## القيود الحالية

- البيانات لا تنتقل بين الأجهزة لأنها محفوظة محليًا.
- لا يوجد نظام صلاحيات.
- لا يوجد ربط مع LMS أو SharePoint.
- الاعتماد على مكتبات CDN خارجية.
