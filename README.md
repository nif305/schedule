# منصة توليد جدول الدورات التدريبية الأسبوعي

مشروع واجهة ثابتة لتوليد جدول الدورات التدريبية الأسبوعي.

## التشغيل من VS Code

```bash
npm install
npm run dev
```

يفتح المشروع على:

```bash
http://localhost:3000
```

## البناء للنشر

```bash
npm run build
```

سيتم إنشاء مجلد:

```bash
dist
```

## إعدادات Vercel

Build Command:

```bash
npm run build
```

Output Directory:

```bash
dist
```

## منطق المنصة

- إدخال رقم الأسبوع والموظف المسؤول.
- إضافة الدورات يدويًا أو استيرادها من Excel.
- توليد قالب Excel جاهز بنفس الأعمدة المطلوبة.
- اختيار نمط تصميم من ستة قوالب.
- توليد صور عرض للشاشات بصيغة ZIP.
- توليد تقرير صورة موجه للوكيل.
- حفظ الجداول السابقة في LocalStorage داخل المتصفح.
